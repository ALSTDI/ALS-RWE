# Companion Tools

These free browser tools from Boyce Data Science go with the sessions. Each link opens the tool on its own page in a new tab, and the full collection is on the [free tools page](https://www.boycedatascience.com/research-tools){target="_blank"}.

## Planning the question

| Tool | What it does | Where it fits |
|:--|:--|:--|
| [Analytic Use Case Generator](https://www.boycedatascience.com/research-tools){target="_blank"} (listed on the free tools page) | Takes a research idea through the OHDSI analytic use cases and gives a feasibility scorecard, with an ATLAS concept set export | [Feasibility First: Sharpen the Question](feasibility-first/01-sharpen-the-question.md) and [Day 3](modules/day-03-cohorts.md) |
| [Network Study Paint By Numbers](https://www.boycedatascience.com/network-study-paint-by-numbers){target="_blank"} | A walkthrough for planning a network study: concept sets, cohort definitions, vocabulary selection in Athena, exposure windows, and network feasibility exercises, with a published OHDSI network study as the worked example | [Feasibility First: Network Feasibility](feasibility-first/05-network-feasibility.md) and Day 6 |
| [Real-World Evidence Literature Map](https://boycelab.github.io/rwe-knowledge/){target="_blank"} | A collection of real world evidence papers shown by disease area, data source, network, trends, and methods | Feasibility First, when you look for prior studies with a similar cohort |

## Building the data

| Tool | What it does | Where it fits |
|:--|:--|:--|
| [The OMOP ETL Worksheet](https://www.boycedatascience.com/omop-etl){target="_blank"} | An interactive worksheet for an OMOP conversion, from profiling the source data and the mapping workshop through semantic mapping, development, testing, data quality assessment, and documentation, with an owner and target date for each step | [Day 1](modules/day-01-omop-cdm.md) and [Day 2](modules/day-02-vocab-dqd.md) |
| [AI-supported OMOP ETL toolkit](https://www.boycedatascience.com/omop-ai){target="_blank"} | A prompt generator and prompt library for ETL work, with a source-to-target mapping record, a project scaffold, a source system profile, and a CDM table and vocabulary reference | Day 1 and Day 2, alongside the worksheet |
| [CDISC SDTM to OMOP mapper](https://www.boycedatascience.com/cdsic-to-omop){target="_blank"} | Maps CDISC SDTM domains to OMOP, with a plan builder and a code starter that writes first-draft ETL code in SQL, R, Python, or SAS | Day 1, for groups that hold clinical trial data |
