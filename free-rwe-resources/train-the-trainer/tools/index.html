    Companion Tools

    These free browser tools from Boyce Data Science go with the sessions. Each link opens the tool on its own page in a new tab, and the full collection is on the free tools page.

    Planning the question

    Tool What it does Where it fits
    Analytic Use Case Generator (listed on the free tools page) Takes a research idea through the OHDSI analytic use cases and gives a feasibility scorecard, with an ATLAS concept set export Feasibility First: Sharpen the Question and Day 3
    Network Study Paint By Numbers A walkthrough for planning a network study: concept sets, cohort definitions, vocabulary selection in Athena, exposure windows, and network feasibility exercises, with a published OHDSI network study as the worked example Feasibility First: Network Feasibility and Day 6
    Real-World Evidence Literature Map A collection of real world evidence papers shown by disease area, data source, network, trends, and methods Feasibility First, when you look for prior studies with a similar cohort

    Building the data

    Tool What it does Where it fits
    The OMOP ETL Worksheet An interactive worksheet for an OMOP conversion, from profiling the source data and the mapping workshop through semantic mapping, development, testing, data quality assessment, and documentation, with an owner and target date for each step Day 1 and Day 2
    AI-supported OMOP ETL toolkit A prompt generator and prompt library for ETL work, with a source-to-target mapping record, a project scaffold, a source system profile, and a CDM table and vocabulary reference Day 1 and Day 2, alongside the worksheet
    CDISC SDTM to OMOP mapper Maps CDISC SDTM domains to OMOP, with a plan builder and a code starter that writes first-draft ETL code in SQL, R, Python, or SAS Day 1, for groups that hold clinical trial data

    Setting up to work

    Tool What it does Where it fits
    GitHub Starter Kit GitHub one step at a time, from account signup through repositories, push and pull, GitHub Pages, GitHub Actions, and MkDocs Module 0, and for facilitators publishing their own copy of this site
    Command Line Starter Kit A plain-language guide to PowerShell and Command Prompt, with a command generator Module 0

    Writing it up

    Tool What it does Where it fits
    Manuscript Paint by Numbers A manuscript planning aid from idea to publication, with a place to report network study findings After Day 6, when a study has results
